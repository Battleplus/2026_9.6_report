# 09 Strengths and Limitations

## Strengths

1. Changes the focus from raw observation prediction to meaningful dynamics.
2. Introduces event-aware representation learning.
3. Provides automatic event generation without manual labels.
4. Improves robustness under visual changes.

## Limitations

1. Event generation depends on thresholds and design choices.
2. Not every detected event is necessarily task-relevant.
3. World model prediction errors still exist.
4. Event extraction may become difficult in complex real-world environments.

## Research Question

How can agents discover task-relevant events automatically?
