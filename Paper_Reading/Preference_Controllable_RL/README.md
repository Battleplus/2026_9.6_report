# Preference Controllable Reinforcement Learning with Advanced Multi-Objective Optimization

## Overview

This folder contains a detailed reading note of:

**Preference Controllable Reinforcement Learning with Advanced Multi-Objective Optimization**

ICML 2025

## Main Idea

The paper proposes Preference Controllable RL (PCRL), which learns a single preference-conditioned policy capable of generating different Pareto-optimal behaviors according to user preferences.
